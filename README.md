# WNS 财经台 · 晨间播报排版台

把「早上好，夜之城！」式的新闻播报文案，排版进主播模板图右侧的文字区，一键导出高清 PNG。

灵感来自《赛博朋克 2077》WNS 新闻台主播斯坦利（Stan）的晨间广播——**"昨天的死人乐透，最后的结果是满打满算的整整三十个！"** 也支持把 A 股复盘写成同款毒舌播音腔。

![效果图](docs/screenshot.png)

## 功能

- **男女主播双模板**：一键切换，同稿换主播零成本
- **标题 / 正文分离**：「新闻大标题」单独放大渲染，留空则从顶部开始
- **独立稿件**：两版文字各自保存、互不影响；可开启「同步」共用一份
- **排版控制**：字号（自动适配 / 手动 + 过大自动兜底）、行距、标题倍数、段距、左对齐 / 居中
- **加粗强调**：`**文字**` 标绿加粗，兼容全角 `＊＊`
- **一键导出 PNG**：2048×1152 高清原图，文字为矢量级清晰
- **本地持久化**：所有文字与排版设置自动保存，刷新不丢
- **自动化回归测试**：24 项端到端测试覆盖全部交互

## 快速开始

### 方式一：双击启动（推荐）

双击 `启动WNS排版台.command`：

1. 自动寻找空闲端口（7200 起，被占用自动 +1）
2. 启动本地服务
3. 自动打开浏览器

关闭那个终端窗口即停止服务，不留后台进程。

> 首次双击如提示安全性：右键 → 打开。

### 方式二：命令行

```bash
npm run dev        # 启动服务，默认 http://localhost:7200/
npm test           # 运行 24 项回归测试（需先 npm install）
```

需要 Node.js ≥ 18（开发依赖仅 `puppeteer-core`，测试用）。

## 使用说明

| 区域 | 说明 |
| --- | --- |
| 主播模板 | 男主播 / 女主播切换；勾选「同步」后两版共用一份标题+正文 |
| 排版 | 自动字号（按文字量适配）/ 手动滑杆（过大自动兜底）；行距、标题倍数、段距；左对齐 / 居中 |
| 新闻大标题 | 单行，按「标题倍数」放大渲染；**留空则不显示** |
| 播报正文 | 多行，空行分段；`**文字**` 加粗标绿 |
| 导出 PNG | 下载 2048×1152 成品图 |

**排版建议**：长稿（300 字以上）用自动字号 + 行距 1.75 + 左对齐；短稿关掉自动，手动 50px+ 居中更有冲击力。

## 项目结构

```

```

## 技术要点

- 文字区坐标来自对模板图的像素级检测（边框左缘 x≈732 / 顶缘 y≈170 / 底缘 y≈1021 / 右侧装饰条 x≈1935–1952），安全文字区 x 804–1864，y 230–982
- 画布与模板同尺寸（2048×1152），导出即原图，无二次压缩
- 字号自动适配：二分查找最大可容纳字号；手动模式超出时自动兜底
- 逐字贪心换行，兼容中英文混排与加粗分段
